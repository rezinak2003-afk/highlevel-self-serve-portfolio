# Loom Walkthrough Script — CRM Knowledge Base (about 2 minutes)

**Before recording:** open the deployed knowledge base, close unrelated tabs, and do not show personal information.

**0:00–0:20 — Introduce the goal**  
“This project is a searchable CRM knowledge base for new users. It is designed to reduce repeated questions by giving users task-based instructions, an expected result, and a safe escalation path.”

**0:20–0:50 — Search and find**  
“Here I search for ‘welcome email’ and filter to Messaging. The article explains when to use the process and the sequence: choose a trigger, write a single-purpose message, test it, and confirm platform permissions.”

**0:50–1:20 — Show the answer format**  
“Each article uses the same structure: the situation, ordered steps, what success looks like, troubleshooting, and references. This makes the content easier to scan and maintain.”

**1:20–1:45 — Show the response template**  
“I can copy a response or escalation template. This helps agents collect the specific details another teammate needs, while reminding them not to ask for passwords or verification codes.”

**1:45–2:00 — Close**  
“The goal is self-serve resolution without overpromising. Where features depend on the software plan, the article calls that out and directs the user to verify current availability.”
